# Personas

## Primary — the solo developer / power user (MVP)

The person building and using it: a developer or power user with a MacBook connected to an external monitor, who wants the internal panel dark to save battery, reduce heat, and cut light without touching the lid.

What they care about, in order:

1. The toggle works every time, and reverses cleanly.
2. Keyboard, trackpad, Touch Bar, and speakers keep working — no behavior change is acceptable.
3. They can never get stuck with a black screen and no way back (safety nets are core, not nice-to-have).
4. Small and free — no account, no tracking, no subscription, no bundleware.

## Secondary — the same person, mid-setup

Someone who has an external keyboard and mouse but still prefers the built-in trackpad/speakers — i.e. clamshell mode's peripheral trade-off is unacceptable, but the "one screen only" outcome is still wanted.

## Anti-persona (explicitly not served in v1)

- A user with no external display who wants an all-black screen (software overlay) — see non-goals.
- A user wanting to pick exactly one of several external displays to keep active — see non-goals.
